## :dart: O guia para alavancar a sua carreira

> Ionic é um framework open source para criar apps móveis, web e desktop híbridos a partir de uma única base de código em HTML, CSS e JavaScript/TypeScript, com componentes de interface que se adaptam ao visual nativo de iOS e Android. Desde a versão 6, o Ionic roda sobre o Capacitor — a camada que empacota sua aplicação web como um app nativo e dá acesso a APIs do aparelho, como câmera, geolocalização, notificações push e Bluetooth — e se integra nativamente com Angular, React e Vue. Este guia reúne documentação oficial, cursos, ferramentas do ecossistema Capacitor, comunidades e um capítulo dedicado a usar IA na prática com Ionic, tudo verificado e organizado para quem já sabe HTML, CSS e JavaScript e quer publicar seu primeiro app nas lojas sem aprender uma linguagem nativa do zero.

## 🤖 IA na prática

Ionic é um framework maduro e bem documentado — exatamente o tipo de ecossistema em que assistentes de IA rendem bem, porque conseguem se apoiar em padrões estáveis (componentes web, plugins de Capacitor) em vez de APIs que mudam toda semana.

**Para aprender**
- Peça para gerar um componente Ionic (ex.: uma tela de lista com pull-to-refresh) e depois explique linha a linha o que cada tag `ion-*` faz.
- Cole a mensagem de erro de build do Xcode ou Android Studio junto com o `capacitor.config.ts` e peça uma explicação da causa mais provável — problemas de sincronização nativa (`npx cap sync`) são comuns e a IA costuma reconhecer o padrão.
- Peça exercícios práticos de navegação com `NavController`/`IonRouterOutlet` (Angular) ou `IonReactRouter` (React), comparando as duas abordagens.
- Peça para transformar um componente Ionic existente em Angular para o equivalente em React ou Vue — é um ótimo jeito de entender o que é do framework e o que é específico do binding.

**Para trabalhar**
- Use [GitHub Copilot](https://github.com/features/copilot), [Cursor](https://cursor.com/) ou [Claude Code](https://code.claude.com/docs/en/overview) para escrever a integração de um plugin de Capacitor a partir da documentação oficial, gerar testes para um componente Ionic e depurar diferenças de comportamento entre iOS, Android e o navegador.
- O [Model Context Protocol](https://modelcontextprotocol.io/) permite conectar ferramentas externas a assistentes de IA; o [awesome-ionic-mcp](https://github.com/Tommertom/awesome-ionic-mcp) reúne um servidor MCP feito especificamente para ajudar a construir apps Ionic/Capacitor com agentes de IA.
- A [Capawesome](https://capawesome.io/docs/ai/mcp/) já expõe seu próprio servidor MCP para builds, deploys e gestão de apps Capacitor a partir de um agente de IA — vale conhecer se você automatiza o pipeline de publicação.
- Depois de qualquer código nativo gerado por IA, rode `npx cap sync` e teste no dispositivo/emulador real: diferenças de permissão e comportamento entre iOS e Android não aparecem só lendo o código.

**Limites e boas práticas**
- IA erra com frequência em nomes de plugins e versões do Capacitor (o ecossistema mudou bastante entre Cordova, Capacitor 2 e as versões atuais) — confirme sempre na [documentação oficial](https://capacitorjs.com/docs/apis) antes de instalar algo sugerido.
- Não cole chaves de API, certificados de assinatura (`.p12`, `.keystore`) ou dados de usuários reais em ferramentas de IA sem verificar a política de privacidade da sua empresa.
- Código nativo (Swift/Kotlin de um plugin customizado) sugerido por IA precisa ser revisado por alguém com experiência na plataforma — um erro ali pode travar a build inteira nas lojas.
